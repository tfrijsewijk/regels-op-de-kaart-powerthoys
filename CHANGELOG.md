# Changelog

Wat er per versie veranderde, de nieuwste bovenaan. Het nummer is de `@version` in de kop van het script, en elke versie heeft een tag in git.

## 1.3.0 (2026-11-26)

Het script heet nu Regels op de kaart PowerThoys en staat in de repo `regels-op-de-kaart-powerthoys`. Een installatie van een eerdere versie schuift vanzelf door naar het nieuwe adres.

## 1.2.0 (2026-11-19)

Naast de knop voor de link staat een knop die onder de kop de verwerkte XML van het document component toont: Gereserveerd, Vervallen, Kop en Inhoud. Het paneel kan wisselen tussen de originele en een opgemaakte versie, en kopieert wat het toont.

## 1.1.0 (2026-10-19)

Naast de titel van het document staat een knop met een wereldbol. Die kopieert een permalink naar het document via de resolver van het Omgevingsloket.

## 1.0.0 (2026-10-17)

Bij de kop van elk document component staat een knop die een link naar dat document component kopieert, met de begindatum van de getoonde versie.
